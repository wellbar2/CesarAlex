# Support

Use the public [GitHub issue tracker](https://github.com/wellbar2/CesarAlex/issues)
for support requests. Before opening an issue, search existing reports and read
the documentation.

For a bug report, include:

- CesarAlex and Python versions;
- operating system;
- the command used to start the application;
- the complete error message or traceback;
- the smallest reproducible example possible;
- whether the curriculum has an ORCID and whether DOI checking was enabled.

Remove API keys, personal data, and confidential Lattes content before posting.
Synthetic examples are strongly preferred.

Questions about methodology or proposed changes to matching rules should be
opened as discussion issues. Security or privacy-sensitive reports should not
include confidential material in a public issue; contact the lead maintainer at
`wellington.rodrigues@usp.br` with a minimal description.

Support is provided on a best-effort basis. Response times are not guaranteed.
